# 作例用の仮素材

11種類のテンプレートに各3枚、計33枚のJPEG静止画があります。追加の22枚（`-2.jpg`、`-3.jpg`）はImageGenで各テンプレートの別カットとして生成しました。各JPEGから軽いズームと移動を加えた4秒の無音ループMP4（`-loop.mp4`）を作成し、プレビューに使用します。被写体そのものが動く完成動画ではありません。従来のSVGも比較用の仮素材として残しています。

管理者が利用権のある無音の動画とポスター画像を確認し、管理画面でURLを差し替えてください。音声で伝える情報を含む動画はこのMVPの素材として登録せず、無音で内容の伝わる作例を使ってください。`silent.vtt` は無音である旨を示す字幕です。

同梱素材は `/demo/ファイル名.jpg` と対応する `/demo/ファイル名-loop.mp4` で参照できます。ループ動画は画面内に入ったときだけ無音で再生し、動きを減らす設定では静止画を表示します。管理者が別途登録する作例動画は利用者の操作で再生します。
