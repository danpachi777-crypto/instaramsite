# 作例用の仮素材

11種類のJPEGはImageGenで各テンプレートの題材に合わせて生成した静止画です。動画の完成品ではありません。画面上では「仮のイメージ」「プレビュー準備中」と明示します。従来のSVGも比較用の仮素材として残しています。

管理者が利用権のある無音の動画とポスター画像を確認し、管理画面でURLを差し替えてください。音声で伝える情報を含む動画はこのMVPの素材として登録せず、無音で内容の伝わる作例を使ってください。`silent.vtt` は無音である旨を示す字幕です。

同梱素材は `/demo/ファイル名.jpg`、動画を追加する場合は `/demo/ファイル名.mp4` などで参照できます。動画は初回表示で事前取得せず、利用者の操作で再生します。
