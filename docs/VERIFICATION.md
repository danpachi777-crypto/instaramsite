## ブラウザーでの確認範囲

ユーザーのChromeでローカルのデモを開き、以下を確認しました。

- デスクトップ表示の紹介ページ、見出し、CTA、状態表示、仮素材。
- 390px幅の紹介ページ・カテゴリー一覧・詳細。特殊効果の絞り込みで1件になること、詳細への遷移、登録欄が無効で同意が未選択であること。

- ローカルの紹介ページを通常のChromeタブで開いた状態にしています。

送信中・保存失敗時の入力保持・再試行・受付完了は、DOM環境のフォームテストで確認しています。実Supabaseを接続したブラウザーでの登録成功や、管理者ログイン後の一覧・編集画面の操作は未確認です。実動画が未提供のため、実素材の再生・字幕・遅い回線・Instagramアプリ内ブラウザーは未確認です。全画面のキーボード操作・すべての画面幅を実機検証したものではありません。

存在しない詳細がストリーミングの影響でHTTP 200になる挙動を修正しました。詳細での404判定をメタデータ生成時にも行い、メタデータを待ってから応答し、一覧の読み込み表示を詳細とは別のルートグループに限定しています。修正後のHTTP 404を確認しています。

## 実Supabaseの結合テスト

前提：破棄可能な専用Supabaseプロジェクトへマイグレーションが適用済みで、管理接続文字列を `TEST_DATABASE_URL` に設定していること。本番データを使わないでください。

```sh
MOTION_DB_TEST_CONFIRM=disposable npm run test:db
```

このスクリプトはRLSと権限のSQLに加え、同じメールの並行登録で初回を維持すること、10要求の同時回数制限で5要求だけが通ることを確認します。自分で作成した検証用レコードだけを最後に削除します。秘密情報を含み得るDBの例外は出力しません。

## 公開前の手動確認

1. READMEに従い必須環境変数、Supabaseの構造変更、seed、管理者UUID、cronを設定する。`DEMO_MODE=false` にし、通常モードで設定不足が表示されないことを確認する。
2. Supabase公開匿名キーで `templates` を読むと公開済みだけが返ることを確認する。登録者のSELECT・INSERTと、回数制限・登録・CSV関数の直接実行が失敗することを確認する。一般のAuthアカウントでも同様に確認する。
3. 管理者だけを許可リストへ登録する。未ログインと、ログイン済みだが未許可のユーザーで、すべての管理ページ・書き込みAPI・CSVが拒否されることを確認する。クッキーを書き換えても保護データが返らないことを確認する。
4. 管理者でテンプレートを作成・編集・並び替え・公開する。公開一覧・詳細・共有情報を確認し、非公開へ戻した後に新しいリクエストで404になることを確認する。別ブラウザー・検索用User-Agentでも下書きが含まれないことを確認する。
5. 実素材のHTTPS URL、利用権、ポスター、縦横比を確認する。スマートフォンとデスクトップで再生ボタンを押し、音声なし・インライン再生・最初に全動画を取得しないことを確認する。動画・画像の失敗時の表示も確認する。
6. Instagram用UTM付きリンクから詳細へ移動し、未選択の同意を自分で選択して登録する。Supabaseに正規化メール、対象テンプレート、登録場所、4つのUTM、同意版、サーバー日時が保存されることを確認する。sessionStorageが利用不可でも登録できることを確認する。
7. 同じメールを別のテンプレート・UTMで再送し、応答が新規と同じで、初回データが変わらないことを確認する。存在しない・非公開のテンプレート、偽の同意、未対応フィールド、過大なJSON、壊れたJSONが保存されないことを確認する。
8. 隠し入力に値がある要求が拒否されること、上限超過が429になり時間後に再開することを確認する。DB障害や信頼できる要求元情報が欠けた状態では503になり、成功表示しないことを確認する。Vercelで複数のサーバーにまたがっても回数制限が継続することを確認する。
9. 管理画面で26件以上の登録を使い、ページ切り替え・テンプレート・日本時間の開始日と終了日を確認する。CSVが現在のページ以外も含むこと、10,000件超では日付分割を案内することを確認する。CSVは式の無害化を維持し、安全な環境で確認する。
10. 個別削除の対象メールが表示され、確認を取り消せること、確定後に対象だけが削除されることを確認する。実在する問い合わせ窓口から配信停止・削除依頼を受け付ける運用も確認する。
11. 他の生成元・Originなしから管理書き込みを送信し拒否されることを確認する。認証クッキーにHttpOnly・SameSite=Lax・本番Secureが付くことを確認する。サービスロールキーがブラウザーのJS・ネットワーク応答・ログに含まれないことを確認する。
12. `cron.job` と `cron.job_run_details` を見て5分間隔の掃除が成功していること、期限切れの識別子が削除されることを確認する。
13. 360〜430pxの実機、デスクトップ、Instagramアプリ内ブラウザー、低速回線で各画面を確認する。Tab移動、本文へのスキップ、フォーカス、フォームの読み上げ、該当なし・読み込み中・失敗・成功、動きを減らす設定を確認する。
14. 運営者名、連絡先、保存期間、委託先・保管場所、規約の下書き、素材の利用権を確認してから集客する。
